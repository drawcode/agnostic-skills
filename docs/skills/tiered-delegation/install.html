#Install tiered-delegation

Install adds the skill folder, optional lean agent profiles, and optionally a pasted rules block. It routes each unit of agent work to the cheapest model tier that can finish it (architect / workhorse / sprinter), with a per-prompt inline-vs-delegate check, an escalation protocol, and three scripts that do the routing and cost math so the model does not.

Install it with its pair, model-routing, which picks the model for any spawn that has no pinned profile and sets the harness default.

#Requirements

  • python3 3.9+ (stdlib only).

  • The scripts are read-only, touch no network, and take --help and --json. Exit 0 is ok, 2 is bad input.

#Install

Claude Code, one project. Nothing changes until you run these.

  1. Copy the skill and make the scripts executable:

    mkdir -p <repo>/.claude/skills
cp -R tiered-delegation <repo>/.claude/skills/
chmod +x <repo>/.claude/skills/tiered-delegation/scripts/*.py

  2. Link the lean agent profiles, one symlink per file:

    mkdir -p <repo>/.claude/agents
for a in runner scout sprinter workhorse architect; do
  ln -sfn ../skills/tiered-delegation/agents/$a.md <repo>/.claude/agents/$a.md
done

  3. Optional, to make the rules standing for every prompt: append prompt-tiered-delegation.md to <repo>/CLAUDE.md or AGENTS.md, and set its Estimator: line to .claude/skills/tiered-delegation/scripts/estimate_delegation.py.

  4. Install model-routing and set the subagent default model as it describes. Then start a new session, since Claude Code reads agents only at session start.

#Check it works

python3 <repo>/.claude/skills/tiered-delegation/scripts/estimate_delegation.py --tokens 20000

Then start a session in the repo and ask what skills it has; tiered-delegation should be listed. The skill triggers on multi-step work.

#Uninstall

Delete the skill folder (or its link) and the pasted block. Nothing else is written anywhere.

Prefer project scope over a global instructions file. A global file is shared with every other project on the machine. A subagent with no pinned model runs at the driver's rate and throws away most of the saving.

Scope: project, machine, shared folder

  • For every project on the machine, use ~/.claude/skills/ and ~/.claude/agents/ instead, and set the subagent default model as the model-routing skill describes, so an un-modelled spawn runs on the mid tier rather than the driver's model.

  • If the project keeps skills canonically somewhere else (a versioned docs folder, say), put the folder there and symlink .claude/skills/tiered-delegation to it rather than copying twice.

Non-Claude models

Map by role, not by name: architect = the strongest reasoning model, workhorse = a solid mid model, sprinter = a small, fast model. Before trusting the small tier with anything past pure extraction, run a quick A/B -- the measured rule is that a haiku-class model loses real quality when it writes ranking or summary fields.

Rule history

  • 2026-10-31 -- harness default and model routing. A machine had the profiles on disk but linked nowhere, so every spawn was a ~37.5k-token generic agent on the driver's Opus. Now CLAUDE_CODE_SUBAGENT_MODEL=sonnet is the floor for any un-modelled spawn, and model-routing / pick_model.py picks sprinter for pure-mechanics briefs.

  • 2026-09-30 -- lean subagent profiles. A generic subagent loaded ~37.5k tokens before its brief (every tool, MCP server, skill list and CLAUDE.md); the profiles load 4.8k-8.2k (16.8k for the architect, which keeps CLAUDE.md), measured on the same one-line task. Subagents were 47% of delegated spend across 126 spawns, so this is the cheapest lever the kit has.

  • 2026-09-25 -- the per-prompt loop is standing: estimate with the script, delegate what fits, tally when cheap, script every deterministic step. Everything stays harness-agnostic.

  • 2026-09-24 -- on a frontier driver, all mechanical work leaves the session, batched into one brief. The only inline exception is a lone scout call.

  • 2026-09-24 -- the small tier does pure extraction only. Judgment scored 1.35 vs 1.86 inline; the mid tier held at 1.91 vs 1.98.

  • 2026-09-24 -- fable is architect tier or above, not a cheap lane.

  • Earlier -- the inline floor: below ~6k tokens of agent overhead, delegation costs more than inline, and terse briefs on trivial work get refused as suspected prompt injection.
